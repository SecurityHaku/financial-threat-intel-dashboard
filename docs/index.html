🔍 CVE / EPSS 個別照会・リスク判定

📖 EPSS (Exploit Prediction Scoring System) とは

EPSSはFIRST.orgが提供する、「今後30日以内にその脆弱性が実際の攻撃（野外）で悪用される確率」をAI/機械学習モデルで算出する動的スコアです。

🔴 EPSS > 0.5 (50%以上)

極めて高い確率で攻撃コードが出回っており、即時パッチ適用が必須です。

🟡 EPSS 0.1 - 0.5 (10-50%)

主要な攻撃手法が存在。境界機器（VPN/Firewall）やAD環境では優先対処対象。

🚨 野外悪用 (In-the-Wild) 悪用確認済み

CISA KEVに登録され、すでに実際の攻撃で悪用が確認された確定脅威です。
